# 03-10-2026

Vortex TSDB 2.0 前端（`frontend/tsdb-web`）：全新实现，基于 Next.js 16、React 19、TypeScript、
Tailwind 4 和 Recharts 3，取代 v1 的 FreeMarker + jQuery 页面。

## 新增

- 数据大屏：每个 category 一个看板，含 KPI 卡片；每个 dimension 一张可折叠卡片，显示瞬时值、
  趋势、采样数和区间仪表；每 3 秒刷新；任意卡片可放大全屏。时间范围 1h/6h/24h，可选移动窗口平滑。
- Categories：置顶、侧栏显示最忙的 10 个、可排序可筛选的全部列表页，以及 ⌘K 快速跳转。
- System health 页：每个节点的 API 速率、错误率和延迟，缓存大小和 Redis 溢出，复制计数与延迟，
  leader、脑裂、mutex 和定时任务，JVM 堆、CPU 和 GC。
- Query explorer：任意 series、范围、步长和窗口，以图表、表格和 API 调用三种形式展示。
- 默认深色主题，可切换浅色；时区默认跟随浏览器，可手动选择。
- `/tsd/*` 代理路由，转发到 `VORTEX_API_URLS`，多个地址之间自动故障切换。
- 配置在 `frontend/tsdb-web/.env`（参见 `.env.example`）：`VORTEX_API_URLS`、`VORTEX_WEB_PORT`。
- standalone 模式的 Dockerfile，由 `run-docker.sh` 部署在 Traefik 网关之后。
- 测试：71 个，Vitest 门槛为语句、分支、函数、行覆盖率各 80%（实测约 96% / 90% / 94% / 98%）。

## 修复

- categories 尚在加载时侧栏误显示 “No data yet”，现在显示 “Loading…”。
- 顶栏时钟引起的 hydration 警告。
